GFG is not one project. It is a connected portfolio containing community operations, game tools, bots, original fiction, games, artwork, websites, archives, and item research.

The strongest implemented project is **GFG Digital Forge / BL4 Editor**. The most urgent preservation project is **100 Goblinz recovery**. **LOOTWROUGHT** has a serious runnable scaffold but still needs real integration testing. **FORGEFALL** is a playable prototype, not a complete game. **Scraps** has meaningful architecture and knowledge files, but its repository does not yet prove a tested, deployed Discord bot. **Goblin Forge Chronicles** has deep canon and several completed side narratives, but the main five-chapter-book Volume I manuscript is incomplete and Volume II has no locked Page One.
